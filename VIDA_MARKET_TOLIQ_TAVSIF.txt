1. LOYIHA NIMA? (QISQACHA)
---------------------------------------------------------------------
Vida — mebel sanoati uchun yagona raqamli ekotizim. U uchta narsani
bitta tizimda birlashtiradi:

  a) MARKETPLACE (Vida Market): xaridorlar mebel firmalari va ustalarini
     o'z hududida topadi, mahsulotni 3D da aylantirib ko'radi, AR orqali
     o'z xonasida sinab ko'radi va buyurtma beradi.
  b) ERP (Vida ERP): mebel firmasi (ishlab chiqaruvchi) uchun boshqaruv
     tizimi — mahsulotlar, buyurtmalar, ishlab chiqarish bosqichlari,
     ombor va materiallar, xodimlar, davomat, ish haqi, ta'minotchilar.
  c) AR / 3D: mahsulotning 3D modeli (GLB) orqali veb-da 3D ko'rish,
     telefonda AR (kengaytirilgan reallik), xona kompozitori (loyiha).

G'oya: "Ishlab chiqarish -> ERP boshqaruvi -> Marketplace -> AR tajriba ->
buyurtma bajarilishi" — hammasi bitta oqimda.

Brend nomi: VIDA ("virtual interier design architect" ma'nosida tanlangan).
Dizayn tizimi: "Forest + Lime" — to'q yashil (#1D3A2F), lime (#D4F06B),
och bej fon (#EEECE6). Shrift: Manrope (veb). Logo: 3D lenta shaklidagi
"V" belgisi (yashil-lime gradient).

3. FOYDALANUVCHI ROLLARI
---------------------------------------------------------------------
Tizim darajasidagi rollar (User.role):
  - platform_admin  — platforma administratori (butun tizim)
  - company_owner   — firma egasi (bitta kompaniya tenanti)
  - employee        — firma xodimi (kasb(lar)iga qarab ishlaydi)

  Yangi firma (0) / Faol firma (bronza) / Ishonchli firma (10+, kumush) /
  Premium firma (100+, oltin). O'rtacha reyting 3 dan past bo'lsa rang
  ogohlantiruvchi (qizil) bo'ladi.

(report), 3 ta shikoyatdan keyin sharh avtomatik yashiriladi.

---------------------------------------------------------------------

  ios/FurniturePlatform/   SwiftUI ilova (XcodeGen: project.yml)

  deploy/       nginx, systemd, env namunalari, backup/restore skriptlari
  docs/, techdocs/   loyiha hujjatlari (45 + 8 ta md fayl, o'zbekcha)

  - Ma'lumotlar bazasi: prod'da MySQL; lokal ishlab chiqishda PostgreSQL
    ham ishlatilgan (DATABASE_URL orqali sozlanadi)
  - Channels + Redis + Daphne/Uvicorn: real vaqt bildirishnomalari (WS)
  - Gunicorn (Uvicorn worker) — systemd xizmati: vida-backend
    (eski serverda: qrbite-backend)
  - Vizual qidiruv: CLIP (open_clip_torch, CPU) + Qdrant vektor bazasi
  - Push: Firebase Cloud Messaging (firebase-admin)
  - SMS: Eskiz.uz (O'zbekiston raqamlari uchun)
  - 3D konvertatsiya: Blender (headless) + unar + assimp (.dae uchun)
  - Fayl saqlash: STORAGE_MODE=local (yoki bulut rejimi)

FRONTEND (veb): React Router 7, three.js (3D ko'rish va xona
kompozitori), lucide-react ikonkalari, tema: yorug'/qorong'i.

iOS: SwiftUI, RealityKit/ARKit (AR), Firebase Messaging, Google Sign-In,
Sign in with Apple, App Attest (qurilma imzosi), Jailbreak aniqlash.

Android: Flutter (Dart), provider, shared_preferences, http.
(Flutter loyihasida iOS platformasi sozlanmagan — iOS alohida native.)

Versiya/majburiy yangilash: backend "AppVersion" (admin boshqaradi);
eski ilova 426 javob olsa — majburiy yangilash ekrani chiqadi.

8. KIRISH (AUTENTIFIKATSIYA), OTP, RATE-LIMIT
---------------------------------------------------------------------
Kirish usullari (mijozlar): telefon + SMS-OTP (6 xonali), Google,
Apple ("Sign in with Apple"), Telegram (bot orqali, @Vida_robot).
Firma/admin: email + parol (JWT; alohida token endpointlari).
Tokenlar: access + refresh (SimpleJWT, refresh rotatsiyasi).

SMS-OTP (apps/users/views.py: _request_otp / _consume_otp):
  - Kod muddati 5 daqiqa; noto'g'ri urinishlar cheklangan
    (PhoneOTP.MAX_ATTEMPTS), undan oshsa kod bekor.
  - Qayta yuborish cooldown'i (standart 60 soniya) va soatiga 5 ta
    so'rov chegarasi (raqam bo'yicha), IP bo'yicha soatlik va umumiy
    kunlik SMS chegaralari (SMS_IP_HOURLY_LIMIT, SMS_DAILY_LIMIT).
  - FAQAT O'zbekiston (+998) raqamlariga SMS yuboriladi
    (SMS_ALLOWED_PREFIXES). Boshqa davlat tanlansa ilova "hozircha SMS
    kod faqat O'zbekiston raqamlari uchun ishlaydi" deb ko'rsatadi va
    Google/Apple/Telegram ni taklif qiladi.
  - Xatolar mashina o'qiydigan kod bilan qaytadi: otp_cooldown (+
    retry_after), otp_hourly_limit, otp_country_unsupported,
    otp_unavailable, otp_send_failed, otp_busy, otp_expired,
    otp_attempts, otp_wrong (+ remaining). Ilovalar xabarni
    foydalanuvchi tilida ko'rsatadi.
  - Kod HECH QACHON ekranda ko'rsatilmaydi. Provayder sozlanmagan (dev)
    muhitda server kodni javobda "debug_code" qaytarishi mumkin
    (faqat DEBUG yoki OTP_DEBUG_RETURN yoqilganda); ilovalarda u faqat
    DEBUG build'da UI-testlar uchun ko'rinmas qiymat sifatida bor.
  - App Store/Play REVIEW demo raqami: APP_REVIEW_PHONE +
    APP_REVIEW_OTP (.env) — shu raqamga SMS yuborilmaydi, kod doim bir
    xil. (Qiymatlar maxfiy, .env da saqlanadi.)
  - SMS yoqish: .env da ESKIZ_ENABLED=true (+ ESKIZ_EMAIL/PASSWORD),
    so'ng xizmatni restart qilish.

Hisob o'chirish: ilova ichida va /delete-account sahifasida so'rov;
admin ko'rib chiqadi; qonun talab qilgan hisobot yozuvlaridan tashqari
shaxsiy ma'lumot o'chiriladi.

  cd backend && source venv/bin/activate
  pip install -r requirements.txt
  python manage.py migrate        (serverda makemigrations ISHLATILMAYDI)
  sudo systemctl restart vida-backend
Frontend yangilash:
  cd ../frontend && npm ci && npm run build
Holatni tekshirish:
  sudo systemctl status vida-backend --no-pager | head -8
  sudo journalctl -u vida-backend -n 50 --no-pager
  deploy/scripts/smoke_test.sh

  python manage.py showcase_translations apply <fayl.json> [--dry-run]
  python manage.py process_model3d ...      (3D konvertatsiya)
  python manage.py backfill_embeddings / backfill_image_signatures
  python manage.py backfill_model3d_bbox     (3D model o'lchamlarini to'ldirish)
