# Project Overview

## 1. Introduction

Furniture Platform — bu mebel sanoati uchun yaratilayotgan raqamli boshqaruv va savdo ekotizimi.

Loyiha maqsadi — mebel ishlab chiqaruvchilar, sotuvchilar, xodimlar va mijozlarni yagona platformaga birlashtirish.

Platforma oddiy ERP yoki oddiy marketplace emas. U ishlab chiqarish jarayoni, mijoz tajribasi va savdo kanalini bitta tizimga birlashtiradi.

---

# 2. Project Vision

## Vision Statement

Dunyo bo'ylab mebel bizneslarini raqamlashtiruvchi, ishlab chiqaruvchidan mijozgacha bo'lgan barcha jarayonlarni boshqaruvchi platforma yaratish.

---

## Long Term Vision

Kelajakda Furniture Platform:

* mebel ishlab chiqaruvchilar uchun asosiy boshqaruv tizimi;
* mijozlar uchun interyer tanlash platformasi;
* ishlab chiqaruvchilar uchun yangi mijoz kanali;
* AR asosidagi virtual showroom

vazifasini bajaradi.
