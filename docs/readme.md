# Furniture Platform

## Global Furniture Commerce & Management Platform

### Version

v1.0

---

# 1. Project Overview

Furniture Platform — bu mebel sanoati uchun yaratilayotgan yagona raqamli ekotizim.

Platforma uchta asosiy qatlamni birlashtiradi:

1. **ERP tizimi**

   * Ishlab chiqarish boshqaruvi
   * Ombor nazorati
   * Material hisobi
   * Xodimlar boshqaruvi
   * Xarajat va foyda tahlili

2. **AR Furniture Experience**

   * Mijoz uyida mebelni virtual ko'rish
   * Xona o'lchamlarini hisoblash
   * Dizayn variantlarini sinash
   * Bir nechta mahsulotlarni joylashtirish

3. **Marketplace**

   * Mebel ishlab chiqaruvchilarni yagona platformaga yig'ish
   * Mijozlarga mahsulotlarni topish imkonini berish
   * Buyurtma jarayonini raqamlashtirish

---

# 2. Vision

Furniture Platform'ning asosiy maqsadi:

> Dunyo bo'ylab mebel ishlab chiqaruvchilar, sotuvchilar va mijozlarni birlashtiruvchi raqamli operatsion tizim yaratish.

Kelajakda platforma faqat mebel bilan cheklanmaydi.

Ekotizim quyidagi yo'nalishlarni qamrab olishi mumkin:

* Mebel
* Oshxona dizayni
* Deraza va eshik
* Oboy
* Pol qoplamalari
* Yoritish
* To'liq interyer yechimlari

# 3. Main Problems

## Customer Problems

* Mebel sotib olishdan oldin qanday ko'rinishini bilmaydi.
* Xona bilan mosligini tasavvur qilish qiyin.
* Buyurtma jarayoni shaffof emas.
* Tayyor bo'lish vaqtini aniq bilmaydi.

## Furniture Company Problems

* Ishlab chiqarish jarayonlari ko'p hollarda qo'lda yuritiladi.
* Material sarfi aniq hisoblanmaydi.
* Mijoz bilan aloqa tizimli emas.
* Mahsulotlarni raqamli ko'rsatish imkoniyati cheklangan.
